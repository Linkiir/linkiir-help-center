# Installation

Select the operating-system guide that matches the Linkiir host.

| Platform | Delivery model | Bundled queue choices |
| --- | --- | --- |
| Windows | Native graphical/silent installer | Kafka, or external Kafka/Redpanda |
| Linux | Native systemd tarball or Docker | Redpanda, Kafka, or external broker |
| macOS | Offline Docker bundle | Redpanda, Kafka, or external broker |

For production, prefer an organization-managed external Kafka or Redpanda cluster rather than a single bundled broker.
